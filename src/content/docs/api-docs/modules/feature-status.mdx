---
title: Cambiar estado de una Funcionalidad
description: Endpoint para activar o desactivar una funcionalidad específica dentro de un módulo.
---

import { Badge, Tabs, TabItem } from '@astrojs/starlight/components';

Permite activar o desactivar una característica específica dentro de un módulo sin afectar las demás herramientas del mismo.

---

## Endpoint

<div style="display: flex; align-items: center; gap: 12px; margin: 16px 0; font-family: monospace; font-size: 1.1rem;">
  <Badge text="PATCH" variant="caution" size="large" />
  <code>/api/v1/modules/features/{'{id}'}/status</code>
</div>

| Entorno | URL Base | Endpoint Completo |
|---|---|---|
| **Producción** | `https://api.mdmexico.online` | <code>https://api.mdmexico.online/api/v1/modules/features/{'{id}'}/status</code> |
| **Local / Dev** | `http://localhost:8000` | <code>http://localhost:8000/api/v1/modules/features/{'{id}'}/status</code> |

---

## Parámetros de la solicitud (Request)

### Parámetros de ruta (Path Parameters)

| Parámetro | Tipo | Requerido | Descripción |
|---|---|---|---|
| `id` | `integer` | **Obligatorio** | ID numérico de la funcionalidad (`ModuleFeature`) a modificar. |

### Encabezados (Headers)

| Encabezado | Tipo | Valor | Obligatorio |
|---|---|---|---|
| `Authorization` | String | `Bearer <token>` | **Sí** |
| `Accept` | String | `application/json` | **Sí** |
| `Content-Type` | String | `application/json` | **Sí** |

### Cuerpo de la petición (JSON Body)

| Campo | Tipo | Valores permitidos | Obligatorio | Descripción |
|---|---|---|---|---|
| `status` | `string` | `"active"` \| `"inactive"` | **Sí** | Nuevo estado asignado a la funcionalidad. |

#### Ejemplo del Body (JSON)
```json
{
  "status": "active"
}
```

### Códigos de Error

#### <Badge text="401 Unauthorized" variant="danger" /> No autenticado
El token no fue provisto en la cabecera `Authorization` o ha caducado.

```json
{
  "message": "Unauthenticated."
}
```

#### <Badge text="422 Unprocessable Content" variant="danger" /> Validación incorrecta
El campo `status` no fue provisto o tiene un valor distinto de `"active"` o `"inactive"`.

```json
{
  "message": "The selected status is invalid.",
  "errors": {
    "status": [
      "The selected status is invalid."
    ]
  }
}
```
