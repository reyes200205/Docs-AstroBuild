---
title: Listar módulos
description: Endpoint para consultar la lista paginada de módulos y funcionalidades del sistema.
---

import { Badge, Tabs, TabItem } from '@astrojs/starlight/components';

Devuelve la lista paginada de todos los módulos registrados en la plataforma, ordenados por prioridad y con su estado actual (`active` / `inactive`).

---

## Endpoint

<div style="display: flex; align-items: center; gap: 12px; margin: 16px 0; font-family: monospace; font-size: 1.1rem;">
  <Badge text="GET" variant="note" size="large" />
  <span>/api/v1/modules</span>
</div>

| Entorno | URL Base | Endpoint Completo |
|---|---|---|
| **Producción** | `https://api.mdmexico.online` | `https://api.mdmexico.online/api/v1/modules` |
| **Local / Dev** | `http://localhost:8000` | `http://localhost:8000/api/v1/modules` |

---

## Parámetros de la solicitud (Request)

### Encabezados (Headers)

| Encabezado | Tipo | Valor | Obligatorio |
|---|---|---|---|
| `Authorization` | String | `Bearer <token>` | **Sí** |
| `Accept` | String | `application/json` | **Sí** |

*(Este endpoint no requiere cuerpo de petición).*

---

## Ejemplos de uso

<Tabs>
  <TabItem label="cURL">
```bash
curl --request GET \
  --url https://api.mdmexico.online/api/v1/modules \
  --header 'Authorization: Bearer 1|p8Qe3Rk...' \
  --header 'Accept: application/json'
```
  </TabItem>
  <TabItem label="JavaScript (Fetch)">
```javascript
const response = await fetch('https://api.mdmexico.online/api/v1/modules', {
  headers: {
    'Authorization': 'Bearer 1|p8Qe3Rk...',
    'Accept': 'application/json',
  },
});
const data = await response.json();
console.log(data);
```
  </TabItem>
</Tabs>

### Códigos de Error

#### <Badge text="401 Unauthorized" variant="danger" /> No autenticado
El token no fue provisto en la cabecera `Authorization` o ha caducado.

```json
{
  "message": "Unauthenticated."
}
```
