Autentica a un usuario registrado en la plataforma mediante sus credenciales (correo electrónico y contraseña). Si la autenticación es exitosa, la API devuelve un token de acceso personal (**Laravel Sanctum**) y la información detallada del perfil del usuario, incluyendo roles, permisos y módulos asignados.

---

## Endpoint

<div style="display: flex; align-items: center; gap: 12px; margin: 16px 0; font-family: monospace; font-size: 1.1rem;">
  <Badge text="POST" variant="success" size="large" />
  <span>/api/v1/login</span>
</div>

| Entorno | URL Base | Endpoint Completo |
|---|---|---|
| **Producción** | `https://api.mdmexico.online` | `https://api.mdmexico.online/api/v1/login` |
| **Local / Dev** | `http://localhost:8000` | `http://localhost:8000/api/v1/login` |

:::note[Autenticación pública]
Este endpoint es público y no requiere ningún token en el encabezado `Authorization`.
:::

---

## Parámetros de la solicitud (Request)

### Encabezados (Headers)

| Encabezado | Tipo | Valor | Obligatorio |
|---|---|---|---|
| `Content-Type` | String | `application/json` | Sí |
| `Accept` | String | `application/json` | Sí |

### Cuerpo de la petición (JSON Body)

| Campo | Tipo | Requerido | Descripción |
|---|---|---|---|
| `email` | `string` (email) | **Obligatorio** | Correo electrónico registrado de la cuenta. |
| `password` | `string` | **Obligatorio** | Contraseña de acceso a la cuenta. |
| `remember` | `boolean` | *Opcional* | Si es `true`, extiende la vigencia del token a 30 días. Por defecto es `false` (expira en 24 horas). |

#### Ejemplo del Body (JSON)
```json
{
  "email": "user@example.com",
  "password": "mi_password_segura",
  "remember": true
}
```

## Respuestas (Responses)

### <Badge text="200 OK" variant="success" /> Login exitoso

El usuario fue autenticado satisfactoriamente. Retorna el token de sesión y el objeto de perfil.

```json
{
  "success": true,
  "message": "Login successful",
  "data": {
    "user": {
      "id": 1,
      "name": "Alejandro Rentería",
      "email": "usuario@mdmexico.online",
      "avatar_url": null,
      "email_verified_at": "2026-01-15T10:00:00.000000Z",
      "password_change_required": false,
      "position": "Software Engineer",
      "roles": {
        "admin": "Administrador"
      },
      "permissions": [
        "view_dashboard",
        "manage_employees",
        "view_reports"
      ],
      "modules": [
        {
          "name": "RH",
          "enabled": true
        },
        {
          "name": "Operaciones",
          "enabled": true
        }
      ],
      "completed_tours": "welcome,dashboard",
      "created_at": "2025-10-01T08:30:00.000000Z",
      "updated_at": "2026-03-20T14:15:00.000000Z"
    },
    "token": "1|p8Qe3Rk..."
  }
}
```

#### Estructura de campos en respuesta 200

| Campo | Tipo | Descripción |
|---|---|---|
| `success` | `boolean` | Indica si la operación concluyó exitosamente (`true`). |
| `message` | `string` | Mensaje descriptivo de la acción (`"Login successful"`). |
| `data.token` | `string` | **Bearer Token de Sanctum** que debe enviarse en las siguientes peticiones. |
| `data.user` | `object` | Objeto con la información y privilegios del usuario autenticado. |
| `data.user.password_change_required` | `boolean` | Si es `true`, el usuario debe cambiar su contraseña antes de usar el resto del sistema. |
| `data.user.roles` | `object` | Roles asignados al usuario en la plataforma. |
| `data.user.permissions` | `array<string>` | Lista de permisos activos para autorización en el cliente. |

### Códigos de Error

#### <Badge text="401 Unauthorized" variant="danger" /> Credenciales inválidas

Ocurre si el correo no existe o la contraseña no coincide.

```json
{
  "success": false,
  "message": "Credenciales inválidas"
}
```

#### <Badge text="403 Forbidden" variant="caution" /> Cuenta inactiva

El correo y la contraseña son correctos, pero el usuario ha sido marcado como inactivo o deshabilitado por un administrador en la base de datos (`is_active = 0`).

```json
{
  "success": false,
  "message": "Tu cuenta se encuentra inactiva. Contacta al administrador."
}
```

#### <Badge text="422 Unprocessable Content" variant="caution" /> Error de validación

Faltan campos requeridos o el formato del correo es inválido.

```json
{
  "message": "The email field must be a valid email address.",
  "errors": {
    "email": [
      "The email field must be a valid email address."
    ]
  }
}
```

#### <Badge text="429 Too Many Requests" variant="caution" /> Límite de intentos excedido (Throttle)

Se han realizado demasiados intentos fallidos consecutivos en un periodo corto. Laravel bloquea temporalmente las peticiones por IP/cuenta.

```json
{
  "message": "Demasiados intentos de acceso. Por favor intenta de nuevo en 60 segundos."
}
```

## Cómo usar el Token en las siguientes peticiones

Para consultar cualquier endpoint protegido de la API (por ejemplo `/api/v1/me` o `/api/v1/employees`), incluye el token obtenido en el encabezado `Authorization` con el prefijo `Bearer`:

```http
Authorization: Bearer 1|p8Qe3Rk...
Accept: application/json
```
